# Senior Quest

Página de estudio para los parciales de Desarrollo de Software (UTN, 3er año): 279 preguntas de Frontend y Backend con la explicación de cada respuesta, repaso de errores, simulacros cronometrados y resumen teórico por tema.

**Sitio:** https://pinini777.github.io/Senior_quest/

- Frontend: HTML, CSS, JavaScript, TypeScript, React y arquitectura MVC en JS.
- Backend: Java (Lombok, DTO, colecciones), Spring Boot, API REST, JPA, mapeo desde UML, JPQL, JUnit 5 y FastAPI.

Es un único archivo `index.html` sin dependencias de compilación. El progreso se guarda en el `localStorage` del navegador.

Íconos de tecnologías: [Simple Icons](https://simpleicons.org) (CC0).
